This is static documentation. The backend isn't hosted — seven JVMs, Kafka, Redis and PostgreSQL cost more to keep running around the clock than a demo justifies, so "Try it out" is switched off here on purpose rather than left to fail. To exercise the API for real, clone the repository and run docker compose up; every endpoint below answers on localhost:8080, and Swagger's interactive mode works there.
